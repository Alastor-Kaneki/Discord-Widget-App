# Discord application configuration

The Android build is configured for Discord application ID:

`1532856977225551912`

Register this mobile OAuth redirect URI in the Discord Developer Portal:

`discord-1532856977225551912:/authorize/callback`

Enable **Public Client** when using Discord's client-side PKCE token exchange.

The application ID is public configuration and is embedded in the APK. Do not commit a Discord client secret, bot token, user token, or any other private credential.
